## Python

Изучаем Python: программирование игр, визуализация данных, веб-приложения.

## Описание

Изучение программирования на Python.

## Цели проекта:

- Изучить основы программирования на Python
- Программирование игр
- Визуализация данных
- Веб-приложения

## Файлы

- `hello_world.py` — первая программа, изучение переменных, строк и функции `print()`
- `simple_message.py` — простые сообщения, работа со строковыми переменными и вывод через `print()`
- `name.py` — работа со строками: методы `title()`, `upper()`, `lower()`
- `full_name.py` — f-строки: подстановка переменных в строку и форматирование вывода
- `apostrophe.py` — апострофы в строках: почему нужны двойные кавычки (демонстрация `SyntaxError`)
- `name_cases.py` - упражнения по строкам: личное сообщение, регистр, цитаты, удаление пробелов (`lstrip()`, `rstrip()`, `strip()`)

## Запуск

```bash
python hello_world.py
python simple_message.py
python name.py
python full_name.py
python apostrophe.py
python name_cases.py
